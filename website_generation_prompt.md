Продукт: **Премиальный On-Premise Telegram-бот для платных подписок (Paywall)**. Бот устанавливается на сервер клиента, берет 0% комиссий, поддерживает крипту и фиат. Целевая аудитория — владельцы крупных крипто- и инфобиз-каналов с высоким доходом, которые ценят безопасность, стиль и независимость.

### ТРЕБОВАНИЯ К ТЕХНОЛОГИЧЕСКОМУ СТЕКУ:
- **Фреймворк:** Next.js 14+ (App Router) + React.
- **Стилизация:** Tailwind CSS (строго использовать utility-classes, никаких внешних CSS файлов кроме globals.css).
- **Типографика:** Шрифт `Inter` или `Geist` (импортированный через next/font/google).
- **UI Библиотека:** Shadcn UI (использовать стилистику компонентов Button, Badge, Card, Accordion).
- **Анимации:** `framer-motion` (микроинтеракции, плавное появление элементов при скролле, hover-эффекты).
- **Иконки:** `lucide-react`.
- **Язык:** TypeScript (строгая типизация).

### ТРЕБОВАНИЯ К ДИЗАЙН-СИСТЕМЕ (VIBE & AESTHETICS):
- **Тема:** Строгий Dark Mode. Основной фон — угольно-черный (`bg-black` или `bg-zinc-950`). 
- **Акценты:** Глубокий индиго (`indigo-500`), неоновый циан (`cyan-400`) и пурпурный. Использовать градиенты для текста (`bg-clip-text text-transparent bg-gradient-to-r`).
- **Текстуры:** Эффект матового стекла (Glassmorphism). Использовать классы `bg-white/5 backdrop-blur-xl border border-white/10`.
- **Освещение:** Добавить фоновые радиальные градиенты (Glow-эффекты), чтобы фон не был скучным и плоским. Тонкие светящиеся рамки на карточках при наведении.
- **Пространство:** Идеальный Whitespace. Огромные отступы между секциями (py-24, py-32), чтобы сайт "дышал" и выглядел дорого. Никакой визуальной каши.

### СТРУКТУРА ЛЕНДИНГА (СТРОГО ПО СЕКЦИЯМ):

**Секция 1: Header (Навигация)**
- Фиксированная шапка с эффектом blur.
- Слева: Строгий логотип (Текст + Иконка).
- По центру: Ссылки на якоря (Преимущества, Калькулятор, Цены, FAQ).
- Справа: Кнопка CTA ("Заказать бота").

**Секция 2: Hero Section (Главный экран - критически важен для конверсии)**
- Сверху маленький анимированный Badge: "✨ Новое поколение автоматизации Telegram".
- H1 Заголовок (очень крупный, tracking-tight, leading-tight): "Автоматизация подписок. Без посредников. Без комиссий." Слово "Без комиссий" должно быть градиентным.
- Подзаголовок: "Установите собственного Paywall-бота на свой сервер. Принимайте криптовалюту и фиат напрямую на свои кошельки. Полный контроль над вашим бизнесом."
- Две кнопки: Primary (Светится, призыв купить за $450) и Secondary (Outline, "Смотреть демо").
- Визуальный элемент: Под текстом должна быть красивая абстрактная 3D-композиция или мокап интерфейса (сделай это с помощью стилизованных div-ов, изображающих карточки транзакций, летающих на фоне).

**Секция 3: Social Proof (Доверие)**
- Текст: "Нам доверяют лидеры крипто-рынка и инфобизнеса".
- Ряд полупрозрачных логотипов (используй иконки или текстовые заглушки), которые бесконечно прокручиваются (Marquee effect).

**Секция 4: Problem-Agitation-Solution (Почему SaaS это зло)**
- Сравнение "Обычный сервис (Paywall)" против "Наш On-Premise Бот".
- Оформить в виде таблицы или двух больших карточек.
- Акцент на то, что конкуренты забирают 5-10%, холдят деньги и могут украсть базу. А наш бот переводит деньги за 0 секунд с комиссией 0%.

**Секция 5: Bento Box Features (Преимущества)**
- Асимметричная сетка (Grid) из карточек разного размера.
- Карточка 1: "Прямые крипто-платежи" (Интеграция CryptoBot/USDT).
- Карточка 2: "Ваша база данных" (PostgreSQL, никто не украдет клиентов).
- Карточка 3: "Защита от блокировок" (Полная анонимность).
- Карточка 4: "Мгновенные инвайты" (Генерация 1-разовых ссылок).

**Секция 6: ROI Calculator (Интерактивная демонстрация выгоды)**
- Напиши React-компонент калькулятора.
- Ползунок (Slider): "Ваш ежемесячный оборот в Telegram" (от $1,000 до $100,000).
- Вывод данных: "Вы отдаете сервисам: $X в месяц. С нашим ботом вы экономите: $X в год."
- Крупная надпись: "Бот окупается за N дней".

**Секция 7: Pricing (Цены - Трехуровневая модель)**
- Оформи 3 карточки тарифов. Центральная карточка (Pro) должна быть выделена визуально (светящаяся рамка, бейдж "Хит продаж").
- Тариф 1: "Basic" ($199). Только исходный код и инструкция.
- Тариф 2: "Pro Turnkey" ($450). Установка под ключ, 2 кассы, месяц поддержки. (Кнопка "Заказать под ключ").
- Тариф 3: "Enterprise" ($990). Whitelabel, реферальная система, кастомная разработка.

**Секция 8: FAQ (Аккордеон)**
- Используй Shadcn Accordion.
- Вопросы: "А это безопасно?", "Нужно ли мне разбираться в коде?", "Что если Telegram обновит API?", "Как принимается крипта?".

**Секция 9: Footer**
- Строгий, минималистичный подвал. Ссылки на контакты, Telegram, GitHub и политику конфиденциальности.
